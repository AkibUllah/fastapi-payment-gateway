FastAPI Payment Gateway

One API in front of bKash, SSLCommerz and Stripe: idempotent requests, a strict payment state machine, HMAC-signed merchant webhooks, fee-aware routing and daily settlement with reconciliation.

Source on GitHub Open in Codespaces Deploy to Render

This page is a static API reference built from the service's exported OpenAPI document on every push to main; there is no backend behind it, so requests cannot be sent from here. Open the Codespace to run the real service with demo data, or deploy your own copy to Render. All /v1 routes except the provider webhooks need an X-API-Key; the Codespace prints a demo merchant key on start.
